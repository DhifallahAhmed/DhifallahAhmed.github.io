Save 01 New

Python · ONNX · Web Workers · Netlify

Scentmate Fragrances

A personality-based fragrance recommender. A short chat asks six questions about you, maps your answers onto 10 personality traits and a learned 64-dimension "scent space", and suggests fragrances whose notes fit you from a catalogue of 40,319 perfumes: much-loved picks first, hidden gems on request. It can also find fragrances similar to one you already love ("I love Dior Sauvage"). The trained model runs entirely in the browser with ONNX Runtime Web in a background thread: no model server, and answers never leave the device.

  • Python data pipeline: cleans the raw Parfumo dataset, imputes accords, classifies gender and scores popularity
  • Personality encoder, catalogue and ranking rules fused into one compact 3.9 MB ONNX model, run in a Web Worker
  • Offline support and instant repeat visits through a service worker and content-hashed, cached-forever assets
  • Quality gate on persona-based evaluations, a 12 MB first-visit size budget, and real-browser smoke tests
  • Netlify Functions + Blobs collect "I'd wear this" feedback for retraining and anonymous health logs
